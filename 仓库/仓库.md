一般分为三部分，入库调度，库内调度，出库调度
Gate签到 → 分配Dock → 安全停靠 → 核对柜号和封条 → 开柜 → 卸货 → Receiving收货区 → 清点与检查 → Staging暂存 → 分配库位 → Put-away上架 → 系统完成入库

# 布局
- **Dock / Loading Dock** 装卸月台
- **Receiving Area** 收货区
- **Staging Area** 暂存区
- **Storage Area** 储存区
- **Picking Area**：拣货区
- **Packing Area**：打包区
- **Outbound Area**：出库等待区
- **Damage / Hold Area**：破损或异常货物区
- **Empty Pallet Area**：空托盘区
- **Yard**：仓库外的柜场或车辆等待区

需要估算拆柜时间
拆柜时间一般受这些因素影响：
- 散装还是托盘装
- 纸箱数量
- 单件重量
- 货物是否规则
- 是否需要重新打托
- 是否需要清点 SKU
- 是否需要贴标签
- 是否存在倒塌或破损
- 月台与柜门是否同高度
- 人员和叉车数量


# 概念
Commodity 货物种类
Stock Keeping Unit 库存中最小识别单位
Piece / PCS 单件
Carton / CTN 纸箱
Package / PKG 包装单位
Pallet / PLT 托盘，叉车用于移动货物的托，palletization便是把散装货物整理到托盘上，形成可由叉车搬运的单位

## 重量
Net Weight 净重，为商品本身的重量，不包括包装。
Gross Weight 毛重，为商品+包装材料的重量。
Tare Weight 皮重，为包装、托盘、集装箱或容器本身的重量
Payload 允许载货重量，可以承受的货物重量上限
