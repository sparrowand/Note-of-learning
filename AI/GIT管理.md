使用ctrl + J唤出终端

# 开始步骤
- `git init .` 初始化仓库
- `git add .`将相关文件增加到缓存区
- `git commit -m "第一版"` 进行备注

# 使用
![[Pasted image 20260722165606.png]]
点击右上角图标，将会显示出Environment 等功能。
![[Pasted image 20260722165736.png]]

![[Pasted image 20260722170125.png]]

## 修改
![[Pasted image 20260722170252.png]]
点击代码旁边的 + 号，即可输入自己的要求，comment后即可让codex做出相应的改动。

## Commit
![[Pasted image 20260722171046.png]]
点击右上角图标，选择Commit Or Push即可将更新后的内容进行手动提交。
也可以直接在输入框中让codex来提交
