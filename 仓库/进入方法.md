**APM Terminals Pier 400**  
**2500 Navy Way, Terminal Island, CA 90731**  
Firm Code: **W185**

**从 710 / Long Beach 方向进码头：**

1. 走 **I-710 South** 一直往港口方向。
2. I-710 South 末端会接到 **Ocean Blvd West**。
3. 过桥进入 **Terminal Island**。
4. 下桥后按港区路牌走，找 **Navy Way**。
5. 到 **Navy Way 左转**。
6. 进入 APM / Pier 400 区域后，司机按 **Truck / Gate / Pier 400** 标志排队进闸，不要走 Visitor 停车入口。
7. 到 gate 前准备好预约号、柜号、车牌/RFID、提单/DO相关信息、TWIC/证件等。

**从 405 北边 / 洛杉矶方向：**

1. 走 **I-405 South**。
2. 转 **110 South / Harbor Freeway** 往 **San Pedro**。
3. 跟着 **Vincent Thomas Bridge / Terminal Island** 指示走。
4. 过 Vincent Thomas Bridge 到 Terminal Island。
5. 到 **Navy Way 右转**。
6. 继续按 **APM / Pier 400 Truck Gate** 标志进司机通道。
