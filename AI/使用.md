# Fork
![[Pasted image 20260722171532.png]]
回滚到目前所选的消息，掐掉后面的消息，配合git可以回滚代码。
会出现一个弹窗。这两个选项区别在于新会话的代码存放地址不同。
![[Pasted image 20260722171627.png]]
## Fork into local
选择此项将会创建一个新的会话，这是从其他会话中复制过来的。只会处理会话内容，代码依旧停留在之前会话的最新版代码。可通过git来配合将代码回滚到想要的版本。
1. git log查看想要版本
2. 复制版本的哈希值
3. git reset --hard 对应哈希值
## Fork into new worktree
通过git worktree实现的功能，会更改当前地址路径，给fork出来的新对话来创建一个新的目录。同样不会回滚代码，仅是将原本项目的代码复制到另一个路径。开辟了全新的隔离目录。

# Agents.md
这是一个放在项目根目录里的配置文件，每次codex开始新对话时，都会读取其中的内容。在想要其每次对话后都进行一个git commit的话可以在其中进行说明。
也可以在里面规定代码风格，命名规范或者是项目规划等。
