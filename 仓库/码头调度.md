# 流程
**海外装货 → 出口港 → 海运 → 美国港口靠泊 → 卸船 → 码头堆场 → 清关和放货 → 卡车提柜 → 仓库卸货 → 还空柜**

码头调度三问：
1. 柜子到哪个码头
2. 预计什么时候可以提
3. 最晚什么时候必须提走

该流程实际结束的标准为空柜在正确地点成功Gate-in，并取得归还凭证。
调度必须确认：

1. 船公司要求还到哪里
2. 归还地点是否接受该柜型
3. 是否需要预约
4. 是否接受船公司的空柜
5. 是否接受带某种Chassis的柜
6. 最晚归还时间
7. 司机是否拿到Empty Return Receipt
 
# 提柜
在集装箱从码头卸下后将会被暂时放在CY Container Yard集装箱堆场
在卡车能够提柜之前需要海关放行，船公司放货，以及码头允许提柜
## 状态
当显示Terminal Release 或者 Container Available时便能进行提柜。
Vessel at Anchorage船已经到港口附近，但还在锚地等待。
Vessel Berthing船正在安排靠泊。
Vessel at Berth船已经靠泊，但柜子可能还在船上。
Container Discharged柜子已经从船上卸下来。但还不一定放到可提区域。

## Last Free Day
简称LFD，为进口柜在码头内不产生Demurrage滞期费用的最后一天，尽量不要安排在当天以免提柜期间出现意外导致延期。

## 预约
为了预防码头产生拥堵，在提柜与还柜时需要进行预约。也就是Terminal Appointment，卡车进入码头提柜或还柜的预约。
提柜需要与司机确认当天是否有空，能否进入码头，车辆是否符合码头要求，是否有适用的底盘，司机的工作时长是否足够。

# Trouble Ticket
当码头系统不能正常处理时，司机便会收到这个。
应马上询问What is the trouble code? Please send me a photo of the ticket. Are you at the trouble window? Did the clerk say what needs to be corrected?

|问题|联系谁|
|---|---|
|Customs Hold|报关行|
|Carrier Hold|船公司或货代|
|Appointment Error|码头预约人员|
|SCAC错误|运输公司后台|
|柜子找不到|码头客服|
|Empty Return拒收|船公司设备部门|
|Chassis问题|Chassis Provider|
# Dual Transaction
双重交易，指司机一次完成还空柜和提重柜两个操作。这可以少跑一次空车，并且节省燃油，提高效率。
