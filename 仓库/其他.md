调度工作很大一部分不是正常流程，而是解决异常。

常见异常包括：

- 船期延误
- 柜子未放行
- 海关查验
- 码头预约不到
- 司机迟到
- 仓库没有 Dock
- 柜号或 Seal Number 不一致
- 货物数量短少
- 外箱破损
- 货物倒塌
- 超重柜
- 仓库地址错误
- 客户临时取消提货
- 空柜无法按时归还
- 系统状态长时间不更新

处理异常时要形成固定习惯：

1. 确认事实；
2. 保存截图、照片和时间记录；
3. 判断影响范围；
4. 联系责任方；
5. 给出新的预计时间；
6. 通知客户和内部人员；
7. 持续跟进；
8. 记录最终结果。



# 表格
### 1. 集装箱追踪总表

包含：

- No.
- Container Number
- BOL
- Carrier
- Vessel / Voyage
- ETA
- Customs Release
- Terminal Release
- Last Free Day
- Pickup Appointment
- Warehouse
- Unloading Date
- Empty Return Date
- Current Status
- Exception Notes

### 2. 每日拆柜计划表

包含：

- 日期
- 到仓时间
- 柜号
- 客户
- 柜型
- 件数
- 托盘数
- 重量
- CBM
- Dock
- 人员
- 叉车
- 预计完成时间
- 实际完成时间

### 3. 仓库库存表

包含：

- 客户
- BOL
- SKU
- 件数
- 托盘数
- 库位
- 入库日期
- 出库数量
- 剩余数量

### 4. 异常记录表

包含：

- 发生时间
- 柜号
- 异常类型
- 问题描述
- 责任方
- 当前处理状态
- 下一次跟进时间
- 最终结果
