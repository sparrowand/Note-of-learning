一个在码头提出集装箱，将集装箱打开，把货物清点出来并转入仓库的过程。一般为客户仓库拆柜，或者是去CFS container freight station按照不同 House B/L，收货人或货物批次分货。
一般流程为： 码头提柜 → 送仓库 → 拆柜 → 清点 → 入库 → 还空柜

discharge 把集装箱从船上卸下来
devanning 拆柜
destuffing 把货物从集装箱中取出
stripping a container 拆箱

# 步骤
## 准备
需先确认基本信息，如：
Container number, Seal number, Delivery Appointment, Packing list, BOL, pallet amount, CTNS amount, Weight, CBM, Cargo Type, Empty Return Instruction 以及Last Empty Return Date.
建议在拆柜之前拍摄集装箱状态以及柜号以防万一。
## 送柜方式
Live Unload 司机在现场等待，仓库立刻拆柜，卸完后司机拉走空柜。空柜可以更快归还，但若过慢会产生司机等待费等。
Drop 司机把重柜放在仓库，之后在来拉空柜。可以灵活安排拆柜时间，但容易占用场地且需要安排第二次提空柜，可能因为拆柜不及时导致detention。

## 清点
一般进行三层核对
第一层核对总托盘数，箱数，总件数。第二层按照产品编号进行核对。第三层对货物状态进行核对。

## 完成后工作
归还空柜，应保存空柜归还凭证。这类材料可以用于应对Detention账单争议。
- 还柜日期和时间
- 还柜地点
- 柜号
- Chassis信息
- Gate-in记录
